ลากบล็อก = เปลี่ยนลำดับ/ย้ายเครื่อง · ลากงานแรกของเครื่อง = เลื่อนทั้งเครื่อง · ลากขอบขวา = ยืด/หด (สินค้า = ปรับตัน) · ชี้บล็อก: + = เพิ่ม Runtime ต่อจากนี้ · − = ลบ Runtime · คลิก = แก้ · Delete = ลบ · ←/→ = สลับลำดับ (งานแรก = เลื่อน 15 นาที)

kg/batch

      ลากหัวการ์ด = สลับลำดับ/ย้ายเครื่อง · แก้ในช่องได้เลย · Batch size (kg) ต่างกันตามสูตร กรอกต่อการ์ด (ว่าง = ใช้ค่าเริ่มต้น) · PLAN ว่าง = FG (kg) ÷ Batch size · พิมพ์ "15 + 5" ได้ (รวม 20) · "ก่อนงานนี้ = หยุด + เคลียร์" แสดงเป็นช่องว่างคั่นรอบ · ตั้งวัน-เวลาเริ่มที่งานแรก (กรอบฟ้า) งานที่เหลือต่อเนื่องเอง — ช่องสีเทา = ต่อจากงานก่อนหน้า
      

    

    

    
เป็นแผนเดียวกับหน้า "แผนเดินเครื่อง" — ย้าย/เพิ่ม/ลบในหน้านี้ ระบบจะเรียงงานของเครื่องนั้นต่อกันใหม่ตั้งแต่งานแรก และใส่ลำดับมาตรฐานให้อัตโนมัติ (เลือก "เปลี่ยนเบอร์ต่อเนื่อง ไม่หยุด" ได้ที่ช่อง "ก่อนงานนี้")

ตรงแผน = จบไม่เกิน ±2 ชม. จากแผน และยอด ≥ 95% · Rate จริง = ยอดจริง ÷ ชม.เดินจริง (ไม่รวม downtime) เทียบ Std Cap ที่ใช้วางแผน · Pareto นับ downtime ที่ไม่ได้วางแผน (เครื่องเสีย + PD) ในช่วงที่เลือก · "ตรวจข้อมูลเวลา" = ชม.เดินจาก Extruder_Runtime ไม่สอดคล้องกับยอด Coater (เช่น บันทึกผิดเครื่อง) ไม่นำไปคิด Rate
