คู่มือใช้งานแบบย่อ

  1. เข้าสู่ระบบ แตะชื่อตัวเอง แล้วใส่ PIN
  2. เลือกเครื่อง แตะแท็บ EXT ด้านบน แล้วเลือก สินค้า และ Lot
  3. เลือกช่วง เริ่มเครื่อง / ปรับจูน / เดินนิ่ง · หยุดเครื่อง ตั้งค่ากลุ่ม Extruder เป็น 0 ให้ แล้วกดบันทึก · กลับมาเริ่มเครื่อง ระบบดึงค่า Default ให้
  4. ปรับค่า ลาก slider หรือกด − / + (กดค้างเพื่อเปลี่ยนเร็ว) · ปิดสวิตช์ "บันทึก" ถ้าไม่ได้วัดค่านั้น
  5. เดินนิ่ง ใส่ เวลาที่ตรวจ และหมายเหตุ แล้วกรอกให้ครบทุกกลุ่ม (แตะหัวกลุ่มเพื่อเปิด)
  6. กด "บันทึกรอบที่ …" ปุ่มใหญ่มุมขวาล่าง · ค่าบน slider ยังอยู่ ปรับต่อได้เลย · ถ้าเน็ตหลุด ระบบเก็บไว้ "รอส่ง" แล้วส่งให้เอง
  7. ใส่ Density ทีหลัง / แก้ค่าที่ใส่ผิด แตะช่องนั้นในตาราง "รอบที่บันทึกแล้ว" (ระบบเก็บชื่อผู้แก้และค่าเดิมไว้)
  8. ข้อมูล Lot (หัวฟอร์ม) กรอกสูตร Die ใบมีด สี น้ำมัน ผู้ตรวจ แล้วกด "บันทึกข้อมูล Lot"
  9. พิมพ์ฟอร์ม กดปุ่ม PDF หรือ Excel ที่ตาราง "รอบที่บันทึกแล้ว"
  10. ย้อนดู Lot ปุ่มด้านบน เพื่อเปิดดู Lot ที่ทำไปแล้ว
  11. เปลี่ยน PIN แตะชื่อตัวเองที่มุมบน
  12. Runtime แตะ Runtime → แตะสี → แตะชื่อสาเหตุ → กด บันทึก · กดเฉพาะตอนเครื่องเปลี่ยน
  13. รีบ ไม่ทันเลือก เลือก …-รอระบุ ไว้ก่อน แก้เสร็จค่อยแตะแถบเหลืองเลือกใหม่
  14. กดผิด / ลืมกด แตะรายการเพื่อแก้ · ลืมกดใช้ปุ่ม "ลืมกด?" · ดูรูปทีละขั้นในคู่มือฉบับเต็ม
  15. แถบแดง NCP Dryer แตะ → แตะแถวสีแดง → เลือกอาหารเป็นอย่างไร (+สาเหตุ) → กด บันทึกคำตอบ
  16. รายงาน NCP Dryer Runtime → รายงานประจำวัน → เลื่อนลงล่างสุด → เลือก 7 วัน
  17. สกรู แตะ สกรู → ดูตันแต่ละท่อน (แดง = ใกล้ครบ) · เปลี่ยนสกรู / แหวนสตีมล็อค กด + บันทึกเปลี่ยนสกรู
  18. ดาย เลือกที่หัวฟอร์ม "หมายเลข Die" → ระบบเพิ่มให้เอง → แตะ ดาย → แถวเหลือง → ใส่ตัน
