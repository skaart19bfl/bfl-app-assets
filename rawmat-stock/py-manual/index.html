3 Master ชุดสารเสริม จัดเตรียมพรีมิกซ์

รายการรหัสชุดสารเสริม (-41) ที่นำเข้าจาก 97-PREMIX.xlsx ประมาณ 1,000 รหัส ถ้ารหัสที่ต้องใช้ยังไม่มี จัดเตรียมพรีมิกซ์เพิ่มเองได้

เพิ่มรหัสใหม่

  1. กด + เพิ่มรหัส
  2. ① เลือกประเภท ชุดสารเสริม (-41) หรือ พรีมิกซ์ (รหัส PX) สำหรับกรณีถุงที่ 2 เป็นพรีมิกซ์
  3. ② ใส่รหัส ③ ชื่อ · กลุ่ม · ④ TTT (ประเภทอาหาร 3 ตัว)
  4. ถุงต่อชุด — 1 ถุง (ปกติ) หรือ 2–4 ถุง สำหรับสูตรที่ต้องแยกถุงเท (ค่าเริ่มต้นตอนรับเข้า)
  5. ⑤ รหัส Odoo ⑥ ชื่อ Odoo (ไม่บังคับ · แก้เพิ่มภายหลังได้ด้วยปุ่ม แก้)
  6. ⑦ กด บันทึก → รหัสใช้ได้ทันทีในหน้ารับเข้าและใบสั่งเบิก

ขั้นที่ 2 · กรอกข้อมูลแล้วกดรับเข้า

  1. คลังที่รับเข้า — PY (ใช้ผลิต BFL) หรือ PY-PC (เตรียมส่ง BFL-PC)
  2. เอกสารระบบ — BFL หรือ BFL-PC = ชื่อบริษัทบนหัวป้าย (เลือกคลัง PY-PC แล้วระบบเปลี่ยนเป็น BFL-PC ให้เอง เปลี่ยนกลับได้)
  3. รหัสชุด — ขึ้น ✓ สีเขียวเมื่อตรงกับ Master
  4. Lot No. — พิมพ์ทั้งเลขในช่องเดียว PRE-FIS261121-01-MI (พิมพ์เล็กได้ ระบบแปลงเป็นตัวใหญ่) ขึ้น ✓ ถูกรูปแบบ พร้อมบอกประเภทและวันที่
  5. จำนวนชุด — 20
  6. น้ำหนักต่อชุด — 13.50 (ระบบคำนวณรวม 270 กก.)
  7. ที่จัดเก็บ — เลือกช่อง (ตัวเลขในวงเล็บ = จำนวนชุดที่มีอยู่แล้วในช่องนั้น)
  8. + เก็บอีกที่ — ถ้า 1 Lot แยกเก็บหลายช่อง ใส่จำนวนของแต่ละช่อง ผลรวมต้องเท่าจำนวนชุด (ขึ้น "รวม 20 / 20 ชุด" สีเขียว)
  9. ใส่ถุงรวมทั้ง Lot (ป้าย -05) — เปิดไว้เมื่อจะรวมชุดใส่ถุงใหญ่ ถ้าเก็บหลายช่องจะได้ถุงละช่อง · ตรวจ Formula Code / Product Name
  10. กด รับเข้า PY · ถ้ายังกดไม่ได้ ดูข้อความ "ยังขาด: …" ท้ายปุ่ม

7 รับคืนชุดสารเสริม จัดเตรียมพรีมิกซ์

11 สแกน เบิก / เท / คืน เทยา

ใช้มือถือ แท็บเล็ต หรือเครื่องสแกนบาร์โค้ด (ยิงแล้วกด Enter อัตโนมัติ) · ปุ่ม 📷 สแกน = ใช้กล้องมือถือ · บัญชีเทยาเข้าระบบแล้วเปิดหน้านี้ให้เอง

A. เบิก — หยิบชุดจาก PY ไปที่ Mixer

  1. เลือกโหมด เบิก
  2. แตะใบสั่ง (Lot การผลิต) ที่จะผลิต — ระบบบอก "หยิบจากที่จัดเก็บ" ว่าต้องไปหยิบ Lot ไหนจากช่องไหน (Lot เก่าก่อน)
  3. สแกนป้ายถุง -05 = เบิกทุกชุดในถุงที่อยู่ในใบ (ไม่เกินจำนวนที่ต้องใช้) · หรือสแกนป้ายชุด -04 ทีละชุด
  4. หรือกด 📷 สแกน เพื่อใช้กล้อง
ตัวอย่าง

ใบ PYO-261120-001 ต้องใช้ FH26MR882ML-41 4 ชุด → สแกน PB-261120-001 (ถุงมี 20 ชุด) → ระบบเบิก 4 ชุด ส่วนที่เหลือ 16 ชุดยังอยู่ในถุง (ข้าม)

B. เท — สแกนทุกชุดตอนเทเข้า Mixer

  1. เลือกโหมด เท
  2. สแกนป้ายชุด -04 ของชุดที่กำลังเท (ต้องสแกนทีละชุด ป้ายถุงใช้ไม่ได้) → ระบบลง batch ให้อัตโนมัติ
ถุงมีหลายรหัส (เช่น ชุด + TITANIUM) ต้องเทและสแกนครบทุกรหัส batch นั้นจึงนับว่าครบ · เมื่อเทครบทุก batch ใบจะเปลี่ยนเป็น "เทครบ" เอง

C. คืน — ชุดที่เบิกแล้วใช้ไม่หมด

  1. รอ Control กด ปิดใบ / สั่งคืน ก่อน (ใบที่ยังเปิดคืนไม่ได้)
  2. เลือกโหมด คืน → สแกนป้ายชุด -04 ทีละชุด หรือป้ายถุง -05 = คืนทุกชุดในถุงที่เบิกแล้วยังไม่เท
  3. นำของไปวางที่ จุดรับคืน ให้จัดเตรียมพรีมิกซ์รับคืน

ชุดที่แยก 2 ถุง (ป้ายมี "ถุง 1/2", "ถุง 2/2")

  1. เบิก — ถ้าถุงแยกกัน ต้องสแกนป้าย -04 ทั้ง 2 ถุง (สแกนถุงแรกแล้วระบบเตือน "ยังไม่สแกนถุง 2") · ถ้าอยู่ในถุงรวม -05 สแกนป้ายถุงรวมครั้งเดียวได้
  2. เท — สแกนป้ายของแต่ละถุงตอนเทเข้า Mixer · ถุงแรกระบบให้เลข batch แล้วรอถุงที่เหลือ (กล่องเหลือง) · batch นั้นจะครบเมื่อเทครบทุกถุง
  3. สแกนเทถุงที่ยังไม่ได้สแกนเบิก → ระบบไม่ให้เท ให้สลับไปโหมดเบิกก่อน
  4. คืน — คืนได้เฉพาะชุดที่ยังไม่ได้เทสักถุง และต้องนำคืนให้ครบทุกถุง

คำถามพบบ่อย

ป้ายหาย / ป้ายเสีย ทำอย่างไร?

หน้า ยอด PY → แถว Lot → พิมพ์ป้าย -04 ใส่เลขชุดที่ เช่น 7 · ป้ายถุงกด ป้ายถุง PB-… หรือ พิมพ์ป้าย -05 ในการ์ดถุงรวม

คืนต้องสแกนป้าย -04 อย่างเดียวหรือไม่?

ไม่ — ได้ทั้ง 2 แบบ ป้ายชุด -04 คืนทีละชุด ป้ายถุง -05 คืนทุกชุดในถุงที่เบิกแล้วยังไม่เท (ทั้งฝ่ายผลิตสแกนคืน และพรีมิกซ์รับคืน) ยกเว้น "ไม่รับคืน" ต้องเลือกทีละชุด

เบิกด้วยป้ายถุง แต่ถุงมีมากกว่าที่ต้องใช้?

ระบบเบิกเฉพาะจำนวนที่ใบต้องใช้ ส่วนที่เหลือยังอยู่ PY ในถุงเดิม (ข้อความ "ข้าม … ชุด")

ทำไมหา Lot การผลิตไม่เจอตอนออกใบ?

แสดงเฉพาะ Lot 30 วันล่าสุดที่ยังไม่ยกเลิกและไม่ Finished · ลองพิมพ์เลข Lot หรือสูตรในช่องค้นหาแล้วกด ค้นหา

ชุดที่รับคืนกลับไปอยู่ในถุงเดิมไหม?

ไม่ — ชุดที่รับคืนออกจากถุงรวม และวางที่จุดรับคืน (หรือที่เลือก) ครั้งต่อไปให้สแกนป้าย -04 หรือจัดถุงรวมใหม่

1 ชุดมี 2 ถุงที่ต้องเท ทำป้ายอย่างไร?

ตั้ง "ถุงต่อชุด = 2" ที่ Master หรือตอนรับเข้า แล้วใส่น้ำหนักแต่ละถุง · รหัส -41 และเลข Lot ไม่เปลี่ยน · ระบบพิมพ์ป้าย -04 ถุงละใบ (ใต้ QR บอก ถุง 1/2, 2/2) · ใบสั่งเบิกแสดง "ชุดละ 2 ถุง" ให้ Control เห็น · เทยาต้องสแกนครบทั้ง 2 ถุง batch จึงครบ

PY กับ PY-PC ต่างกันอย่างไร?

PY = ใช้ผลิตของ BFL (ใบสั่งเบิก/เท) · PY-PC = เตรียมไว้ส่ง BFL-PC ออกได้ทางเมนู จ่ายออก PY-PC เท่านั้น · ยอดแยกกัน (หน้า ยอด PY มีปุ่มเลือกคลัง) · ใช้ช่องจัดเก็บ Zone A/B ร่วมกัน

เอกสาร BFL-PC เปลี่ยนอะไร?

เปลี่ยนเฉพาะชื่อบริษัทบนหัวป้าย -04 / -05 เป็น "บริษัท บลูฟาโล่ เพ็ทแคร์ จำกัด" · รหัสฟอร์ม/Rev และช่องเหมือนเดิม · F-WI07 / F-WI04 ของฝ่ายผลิตยังเป็น BFL

บันทึกย้อนหลังได้ไหม?

การยกเลิก/แก้ไขรายการของวันก่อน (รอบวันเริ่ม 08:00) ต้องให้ admin ทำ

ใช้ภาษาอังกฤษได้ไหม?

กดปุ่ม EN ที่แถบบนเพื่อสลับภาษาเมนู (คู่มือนี้เป็นภาษาไทย)
